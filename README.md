# English Learning App

Локальное MVP-приложение для практики английского через реальные ситуации, полезные конструкции и собственные ответы. Интерфейс помогает пройти короткий спринт из семи заданий, сохранить фразы для повторения и импортировать следующий спринт в JSON-формате.

## С чего начать

Перед работой с проектом прочитай [описание проекта и MVP](docs/read-first/01-project-overview-ru.md).

Для запуска на своём компьютере нужны [Node.js](https://nodejs.org/) и Git:

```powershell
git clone https://github.com/yuliiadziuba/english-app.git
cd english-app
npm.cmd ci
npm.cmd run dev
```

Открой адрес, который появится в терминале. Обычно это `http://localhost:5173`.

## Что уже работает

- Пример недельного спринта из 7 заданий на уровнях B1–C1: обычно одно задание или одна тема на день, без дедлайнов и штрафов за пропуски.
- Цикл обучения: понять контекст → заметить конструкцию → восстановить → вспомнить → применить.
- Проверка закрытых ответов по подготовленным вариантам.
- Сравнение свободного ответа с естественными примерами без автоматической оценки ИИ.
- Русские пояснения к условиям и переводы полезных английских фраз по нажатию.
- Возврат к предыдущему шагу, спокойное завершение через `Finish for now` и повторное прохождение задания или спринта.
- Импорт JSON-спринта с проверкой, preview семи заданий и понятными ошибками.
- Локальное сохранение прогресса, ответов, выбранных фраз и заметок в браузере.

## Важно о данных

Это локальный MVP без аккаунтов и сервера. Учебные данные сохраняются только в браузере текущего устройства. Очистка данных сайта, другой браузер или другой компьютер не перенесут прогресс.

Позднее проект можно расширить аккаунтами и облачным хранением, не меняя формат заданий и основную механику практики.
